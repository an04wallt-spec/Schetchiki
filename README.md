# Счётчики — эталонная рабочая база v0.5

Этот репозиторий строится только вокруг реально работающего APK:

`baseline/Schetchiki-v0.5-FINAL.apk`

SHA-256:
`3b9ef13a6225948aa88336740577fa8cd3b11f853d4c4746c9817aa773ce139d`

## Главное правило

Рабочую v0.5 нельзя пересоздавать, переписывать или подменять новым Android-проектом.
Любая доработка выполняется только от эталонного APK:

1. Проверить SHA-256 baseline.
2. Декомпилировать именно этот APK через apktool.
3. Внести только согласованную точечную правку в smali/resources.
4. Собрать APK обратно.
5. Подписать тем же ключом разработки, который используется для следующих обновлений.
6. Проверить, что остальная логика и интерфейс не изменились.

## Текущая единственная задача

Двойное нажатие на существующую плашку `ИСТОРИЯ` должно временно разрешить редактирование сохранённых показаний выбранного архивного месяца через уже существующий редактор показаний.

Нельзя менять внешний вид, расчёты, прогноз, средний расход, порядок счётчиков, переход месяцев, структуру хранения данных и любые другие кнопки/обработчики.

Подробности: `docs/CHANGE_REQUEST.md`.
