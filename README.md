# Счётчики

Репозиторий для безопасной дальнейшей разработки Android-приложения **«Счётчики»**.

## Главное правило

Файл `reference/Schetchiki-v0.5-FINAL.apk` — **неприкосновенный эталон рабочей версии**. Его нельзя редактировать, пересобирать, заменять или использовать как место для экспериментов.

Контрольная сумма эталона:

`SHA-256 3b9ef13a6225948aa88336740577fa8cd3b11f853d4c4746c9817aa773ce139d`

GitHub Actions перед каждой сборкой автоматически проверяет эту сумму. Если эталон изменится, сборка остановится.

## Структура

- `app/` — исходный Android-проект для дальнейшей разработки.
- `reference/` — рабочая v0.5 и её DEX для сверки. Не менять.
- `docs/BASELINE.md` — зафиксированная логика рабочей версии.
- `docs/NEXT_CHANGE.md` — следующая требуемая правка: двойной тап по «ИСТОРИЯ».
- `scripts/verify_reference.py` — проверка, что эталон v0.5 не повреждён.
- `.github/workflows/build-apk.yml` — автоматическая сборка APK.

## Как завтра создать репозиторий

1. Создать на GitHub пустой репозиторий, например `Schetchiki`.
2. Не добавлять README/.gitignore при создании — они уже есть здесь.
3. Распаковать ZIP и загрузить **содержимое папки**, а не саму внешнюю папку целиком.
4. Сделать commit в `main`.
5. Открыть вкладку **Actions** — должна запуститься `Build APK`.
6. После зелёной сборки APK будет внизу страницы запуска, раздел **Artifacts → Schetchiki-debug**.

## Важно про установленную v0.5

Не удаляйте рабочую v0.5 с телефона ради проверки первой GitHub-сборки. Сначала новую сборку надо проверить отдельно. Подпись APK из GitHub без старого приватного ключа будет другой, поэтому установка поверх уже установленной v0.5 может быть невозможна — это нормально и не означает ошибку программы.

## Текущий статус исходников

Исходники в `app/` — чистая восстановленная база по известной логике v0.5. Эталоном поведения всё равно остаётся `reference/Schetchiki-v0.5-FINAL.apk`. Любое изменение должно сравниваться с ним и ограничиваться конкретной задачей.
