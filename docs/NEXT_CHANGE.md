# Следующая правка — только одна

## Задача

Не переделывая и не изменяя остальную работу программы, сделать существующую плашку **«ИСТОРИЯ»** активной по **двойному нажатию**.

После двойного нажатия пользователь должен иметь возможность вручную изменить сохранённые показания **выбранного архивного месяца** штатным редактором показаний.

## Что запрещено менять

- расчёт прогноза;
- переход между месяцами;
- порядок и данные четырёх счётчиков;
- средние расходы;
- формат ключей SharedPreferences;
- внешний вид остальных элементов;
- июльские данные;
- уже сохранённые данные пользователя;
- эталонный APK v0.5;
- любую логику, не связанную непосредственно с разблокировкой архива.

## Желаемое поведение

1. Открыть архивный месяц.
2. Обычное одиночное нажатие ничего не меняет.
3. Быстро дважды нажать по «ИСТОРИЯ».
4. Только выбранный архивный месяц временно становится редактируемым.
5. Нажатие на карточку счётчика открывает тот же редактор значения, что используется для разрешённого редактирования.
6. После сохранения новое значение записывается в существующий ключ `reading_YYYY-MM_INDEX`.
7. Никакие соседние месяцы напрямую не переписываются; их прогноз пересчитывается штатной логикой.
8. После выхода из режима/перезапуска приложения архив снова заблокирован.

## Приёмка

Правка считается готовой только если:

- приложение запускается;
- текущий месяц работает как раньше;
- прогноз следующего месяца совпадает с базовой логикой;
- одиночный тап по «ИСТОРИЯ» не разблокирует архив;
- двойной тап разблокирует только текущий выбранный архивный месяц;
- изменённое архивное значение сохраняется после перезапуска;
- никаких других визуальных или функциональных изменений нет.
