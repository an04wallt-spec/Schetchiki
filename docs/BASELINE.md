## Хранение

Показание месяца:
`reading_YYYY-MM_INDEX`

Средний расход:
`average_INDEX`

Показание, сохранённое вручную для конкретного месяца, имеет приоритет над прогнозом.

## Правило расчёта v0.5

Если для месяца нет сохранённого вручную значения:

`значение месяца = разрешённое значение предыдущего месяца + текущее среднее`

Расчёт цепочкой работает через несколько месяцев. Именно эта логика исправлена в рабочей v0.5 и **не должна меняться** при добавлении редактирования архива.
