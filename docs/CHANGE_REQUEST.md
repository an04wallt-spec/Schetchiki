# Единственное изменение относительно рабочей v0.5

## Требование

В существующем рабочем приложении v0.5:

- плашка `ИСТОРИЯ` визуально остаётся без изменений;
- одиночный тап не получает нового поведения;
- двойной тап по `ИСТОРИЯ` включает временный режим редактирования выбранного архивного месяца;
- после разблокировки пользователь может нажать на сохранённое показание и изменить его штатным редактором, уже существующим в v0.5;
- средний расход в архиве не редактируется;
- режим предназначен только для ARCHIVE, не для FUTURE;
- остальные функции приложения должны вести себя точно как в рабочей v0.5.

## Запрещено

- создавать новый интерфейс;
- переносить приложение на другой UI-фреймворк;
- переписывать MainActivity с нуля;
- менять цвета, размеры, подписи или расположение элементов;
- менять формулы прогноза;
- менять рабочую логику `valueForMonth`;
- внедрять показания программно;
- использовать v0.6/v0.7/v0.8 как основу.
