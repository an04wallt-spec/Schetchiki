# Рабочий процесс

1. Baseline APK остаётся неизменным.
2. CI проверяет его SHA-256.
3. Отдельная job декомпилирует baseline через apktool.
4. Изменения делаются только в полученном smali/resources.
5. Патч должен быть минимальным и обозримым в diff.
6. APK собирается обратно через apktool.
7. Перед выдачей пользователю проверяются ZIP-структура, `classes.dex` и подпись.

Не допускается создание отдельного Android-проекта, визуально имитирующего приложение.
