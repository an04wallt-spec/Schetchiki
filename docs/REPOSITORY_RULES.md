# Правила работы с репозиторием

1. `reference/` — только чтение.
2. Каждая задача — отдельная ветка.
3. Не объединять несколько исправлений в один commit/PR.
4. Перед изменением зафиксировать, что именно разрешено менять.
5. После изменения проверить GitHub Actions.
6. APK пользователю выдавать только из успешной сборки.
7. Не хранить в GitHub приватные ключи подписи, пароли и keystore.
8. Если изменение требует затронуть логику вне задачи — остановиться и сначала доказать необходимость.
